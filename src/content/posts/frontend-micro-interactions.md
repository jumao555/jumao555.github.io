近几年从 macOS、visionOS 到众多顶级独立开发者博客，**通透毛玻璃（Glassmorphism）**重新回归主流审美。但真正做进项目里时，很容易踩进“背景脏、文字看不清”的坑。

## 通透感的三个黄金要素

### 1. 柔和的低频背景光晕

毛玻璃本身没有颜色，它的高级感来自**透过玻璃看到的柔和渐变**。如果底层是一堆杂乱的高频噪点或高对比度文字，模糊之后只会显得凌乱。

因此最稳妥的做法，是在页面最底层放置 2~3 个大半径、低透明度的缓慢流动光斑（Ambient Orbs），让半透明卡片在滚动时泛出微妙的色彩呼吸感。

### 2. 微妙的 1px 亮色内描边

真实世界里的磨砂玻璃边缘会折射光线。在 CSS 中，仅仅写 `backdrop-filter: blur(20px)` 往往显得扁平，加上一条细腻的半透明边缘高光就能瞬间立起来：

```css
.glass-card {
  background: rgba(255, 255, 255, 0.74);
  backdrop-filter: blur(20px) saturate(160%);
  border: 1px solid rgba(255, 255, 255, 0.85);
  box-shadow:
    0 8px 30px -12px rgba(30, 58, 95, 0.08),
    0 1px 2px rgba(15, 23, 42, 0.03);
}
```

### 3. 暗黑模式切忌纯黑 `#000000`

高质感的暗黑模式通常带有极淡的色相倾向（比如 `hsl(var(--hue), 24%, 8%)` 的午夜蓝灰），再叠加一层 `inset 0 1px 0 rgba(255, 255, 255, 0.06)` 的顶部微光，界面会像一块温润的黑曜石，既护眼又不失精致。

## 克制的微交互更有生命力

> 动效不是为了炫技，而是为了给每一次点击与悬停一个符合直觉的物理反馈。

在卡片悬浮时上浮 `3px`、导航栏激活项用弹簧曲线平滑滑移、点击点赞按钮时绽放轻巧的微粒——这些细节单看微不足道，组合在一起却构成了网站独一无二的“手感”。
